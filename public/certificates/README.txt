===============================================================
CERTIFICATES DIRECTORY — VIJAYARAGAVAN V PORTFOLIO
===============================================================

Place your high-resolution original individual certificate images
(PNG, JPG, or WebP) in this folder.

To link an individual certificate image to its card and modal preview:
1. Save the image file here, e.g.:
   - google-ai-essentials.png
   - nptel-programming-c.png
   - simplilearn-genai-studio.png
   - claude-code-action.png
   - html-with-ai.png
   - vyld-2027.png
   - intellipaat-ai-bootcamp.png
   - capricious-wifi-pentesting.png
   - kongu-full-stack.png
   - esec-sparse-graphs.png
   - capricious-cybersecurity.png
   - simplilearn-intro-ai.png
   - claude-code-101.png

2. Open `src/data/certificates.ts` and set the `image` field:
   image: '/certificates/google-ai-essentials.png'

Until an image is specified, the application automatically renders
an authentic, styled certificate badge with full title, issuer,
and verification ID.
